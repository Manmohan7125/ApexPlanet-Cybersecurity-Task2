# ApexPlanet Cybersecurity Internship – Task 2
## Network Security & Scanning

**Intern:** Man Mohan Beniwal  
**Task:** Task 2 – Network Security & Scanning  
**Timeline:** Days 13–24

## Objective
Learn reconnaissance, scanning, and network traffic analysis in a controlled lab environment.

## Activities
1. Reconnaissance: WHOIS, Nslookup, Google Dorking, Shodan, Ping Sweep, Banner Grabbing
2. Nmap: TCP SYN (`-sS`), UDP (`-sU`), Service Detection (`-sV`), OS Detection (`-O`)
3. Vulnerability Scanning: OpenVAS or Nessus Essentials against Metasploitable2
4. Wireshark: HTTP, FTP, DNS, unencrypted FTP credential filtering, SYN-flood analysis
5. Firewall: simple iptables allow/deny rules and port-scan blocking

## Deliverables
- Nmap Scan Report
- OpenVAS Vulnerability Report
- Detailed scan analysis
- 5-minute demonstration video
